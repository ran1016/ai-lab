### Knowledge — AI 知识库

```python

title       VARCHAR  标题
content     TEXT     正文（助手回答依据）

```

### Profile — 个人资料

```python
id          INTEGER  主键
```

关键设计决策：

- Knowledge 表纯文本存储，对话时全量注入系统提示

## 四、功能模块详解

### 4.1 AI Stack 能力图谱

3 个并列椭圆（AI / DATA / 产运），每个椭圆独立拖拽旋转。

**关键实现：**
- 椭圆参数方程：`x = cos(θ) × RX, y = sin(θ) × RY`
- RX=130, RY=72（每个椭圆），三个椭圆 grid 布局 gap=50px
- 鼠标拖拽 → 计算水平位移 → 叠加到 rotation 角度
- `requestAnimationFrame` 惯性滑行（vx 衰减 0.94/帧）
- 自动旋转速度 `0.00012` 弧度/ms
- 三个核心球错开节拍：`coreBounce` 动画 + `animation-delay`

**踩坑：** 核心球太大（原 150px → 最后 100px），光晕太强，多轮调整后达到视觉平衡。

### 4.2 Evolution 技术成长路线图

按年份分组，区分技术成长（tags 含"技术成长"）和行政经历。

- 年份徽章 + 渐变连接线 + 玻璃卡片
- `build_roadmap()` 数据预处理：按年份倒序排列
- 状态徽章：Published / Researching / Building / Archived

### 4.3 自定义视频播放器

完全自研，零第三方依赖。

```javascript
// VP 组件结构
.vp
  ├── .vp-video      <video> 原生元素（隐藏 controls）
  ├── .vp-play       SVG 播放/暂停按钮
  ├── .vp-controls   30px 暗色控制条（悬浮显示）
  │   ├── .vp-progress  进度条
  │   ├── .vp-time      时间显示
  │   └── .vp-mute      静音切换
```

关键函数 `initVp(vp)` 初始化单个播放器，支持 Modal 内 `vp-inline` 模式。

### 4.4 多媒体画廊

每个 Item 可关联多张媒体，前台通过 `pg-gallery` 组件翻页展示。

- 箭头按钮（‹ ›）翻页
- 页码指示器（1/3）
- 翻页后自动初始化新出现的视频播放器
- 支持图片/视频/PDF/PPT 混合

### 4.5 角落 AI 助手

内嵌 LLM 驱动的聊天助手，支持知识库自建。

**交互流程：**
1. 用户点击角落人物 → 弹出聊天面板
2. 知识库内容→ 全量注入系统提示（目前方案）
3. 用户问题 + 知识库 + 人设 → 发给 DeepSeek API
4. 大模型基于知识库内容回答

**技术细节：**
- 系统人设包含：主人姓名、一句话定位、个人简介、核心能力、代表项目
- 知识库内容以 `• 标题：内容` 格式追加到提示中
- 输入框支持 Enter 发送 / Shift+Enter 换行
- 自动撑高 textarea（max 120px）
- 打字中动画（三个弹跳点）

**踩坑：** PythonAnywhere 免费版禁止访问非白名单 API（SenseNova），后改用 DeepSeek。markdown 包缺失需要手动 `pip install`。

### 4.6 动效系统

| 动效 | 实现方式 |
|---|---|
| 弹跳进入 | `@keyframes bounceIn`（34→-6→4→-2→0px） |
| 丝滑导航滚动 | 1000ms `easeInOutQuart` 自定义 |
| 星空粒子 | Canvas + `requestAnimationFrame` |
| 玻璃拟态 | `backdrop-filter: blur(20px)` + `rgba(15,23,42,0.65)` |
| 卡片浮动 | `@keyframes mascotFloat`（4s 周期 6px） |
| 核心球呼吸 | `@keyframes coreBounce`（2.6s 周期 + 错开延迟） |
| 项目媒体悬停 | 图片 1.06 倍缩放 + 边框发光 + 整体 8px 抬起 |

## 六、踩坑记录

### 1. SQLAlchemy `order_by` 编译错误

`CompileError: Can't resolve label reference`  
→ 原因：`order_by` 在关系定义时立即求值  
→ 解决：改用 lambda 延迟求值  
```python
order_by=lambda: (Media.sort_order, Media.created_at)
```

### 2. `NOT NULL constraint failed: media.item_id`

→ 原因：Media 外键需要 item.id，但新 Item 还没 flush  
→ 解决：save_item 中先 `db.session.flush()` 拿到 id 再操作 Media

### 3. Form 嵌套导致提交失败

→ 原因：批量删除 `<form>` 内嵌了单删 `<form>`，HTML 不支持 form 嵌套  
→ 解决：单删用 JS 动态提交到隐藏的独立表单

### 4. PythonAnywhere `activate_this.py` 不存在

→ 原因：Python 3.12 已弃用 `activate_this.py`  
→ 解决：改用 Virtualenv 路径配置

### 5. SenseNova API 被 PythonAnywhere 防火墙拦截

→ 原因：免费版只允许白名单域名  
→ 解决：改用 DeepSeek（`api.deepseek.com`）

### 6. 本地 site.db 为 0 字节

→ 原因：Flask 未启动时数据库未写入  
→ 解决：先 `python app.py` 再查看

### 7. 聊天面板 Hidden 属性被 CSS 覆盖

→ 原因：`.chat-panel` 的 `display: flex` 优先级高于 `[hidden]`  
→ 解决/补加：`.chat-panel[hidden] { display: none; }`
